= OpenCode

OpenCode is an open source AI coding agent for the terminal. It supports remote MCP servers over HTTP, so it connects to the Vaadin MCP server directly.

== Configuration

Add the following to `opencode.json` in your project root:

[source,json]
----
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "vaadin": {
      "type": "remote",
      "url": "https://mcp.vaadin.com/docs",
      "enabled": true
    }
  }
}
----

Create the file if it doesn't exist. If it already has an `mcp` entry, add `vaadin` to it. Restart OpenCode afterwards.

== Verify the Setup

After restarting OpenCode:

. Start a new session in your project
. Ask a question about Vaadin development (e.g., "How to create a Grid in Vaadin?")
. OpenCode queries the Vaadin MCP server for relevant documentation
