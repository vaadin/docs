= Junie

Junie is JetBrains AI assistant for IntelliJ-based IDEs. It uses stdio transport and requires an adapter to connect to HTTP-based MCP servers like the Vaadin MCP server.

*Requirements:*

* Node.js 18 or later
* Junie plugin for IntelliJ-based IDEs

== Configuration

. Open the IDE settings: kbd:[Ctrl+Alt+S] on Windows and Linux, kbd:[Cmd+,] on macOS.
. Go to menu:Tools[Junie > MCP Settings].
. Click [guibutton]*Add* and paste the following configuration into the `mcp.json` file that opens:

[source,json]
----
{
  "mcpServers": {
    "vaadin": {
      "command": "npx",
      "args": ["@pyroprompts/mcp-stdio-to-streamable-http-adapter"],
      "env": {
        "URI": "https://mcp.vaadin.com/docs",
        "MCP_NAME": "vaadin"
      }
    }
  }
}
----

The adapter bridges stdio transport to HTTP, allowing Junie to communicate with the Vaadin MCP server. `URI` is the server's address, and `MCP_NAME` is the name the server appears under.

[NOTE]
====
Servers added through the [guilabel]*MCP Settings* page are saved to `~/.junie/mcp/mcp.json` in your home directory and are available in every project. To limit the server to one project, save the configuration as `.junie/mcp/mcp.json` in that project's root instead.
====

== How the Adapter Works

The `@pyroprompts/mcp-stdio-to-streamable-http-adapter` package:

. Receives stdio commands from Junie
. Translates them to HTTP requests
. Forwards requests to the Vaadin MCP server
. Returns responses back through stdio

This allows stdio-only tools to work with HTTP-based MCP servers.

== Verify the Setup

After configuration:

. Check the [guilabel]*Status* column of the server list in menu:Tools[Junie > MCP Settings]. Expand it to see the Vaadin server's tools.
. Open the Junie assistant panel
. Ask a question about Vaadin development (e.g., "What are Vaadin components?")
. Junie queries the Vaadin MCP server through the adapter
