= Cursor

Cursor is an AI-powered code editor with native HTTP MCP support, making it easy to integrate with the Vaadin MCP server for enhanced documentation access.

== Configuration

Cursor reads MCP servers from an `mcp.json` file. Choose where to save it:

* *This project:* `.cursor/mcp.json` in the project root. Everyone who opens the project in Cursor gets the server, so commit the file to share it.
* *All your projects:* `~/.cursor/mcp.json` in your home directory (`%USERPROFILE%\.cursor\mcp.json` on Windows).

Add the following configuration to the file:

[source,json]
----
{
  "mcpServers": {
    "vaadin": {
      "url": "https://mcp.vaadin.com/docs"
    }
  }
}
----

Create the file if it doesn't exist. If it already has an `mcpServers` entry, add `vaadin` to it. Restart Cursor afterwards.

== Verify the Setup

After restarting Cursor:

. Open the AI chat panel
. Ask a question about Vaadin development (e.g., "Show how to create a form in Vaadin")
. Cursor automatically queries the Vaadin MCP server for relevant documentation
