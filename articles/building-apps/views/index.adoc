= Views & Navigation

A view is the part of the user interface that changes when the user navigates in the application. Typically, it takes up most of the page. These guides show how to add views to your application, navigate between them, and pass data from one view to another.

Start with <<add-view#,Add a View>> and <<navigate#,Navigate to a View>>. Most applications also need a <<add-router-layout#,router layout>> that all views share, with a <<add-navi-menu#,navigation menu>>. <<pass-data#,Pass Data to a View>> covers route parameters, query parameters, and other ways of passing data. <<add-master-detail#,Add a Master-Detail View>> shows a common pattern for views that list items and show the details of the selected one.

To control which users can open which views, see <<../security/protect-views#,Protect Views>>. To add client-side views written in React, see <<../react#,React Views>>.
