= Components

Vaadin comes with a large set of ready-made <<{articles}/components#,components>>. These guides show how to create components of your own, either in Java or by wrapping existing client-side code with a Java API.

To build a reusable component in Java, start with <<build-component#,Build a Component>> and <<style-component#,Style a Component>>. To share it between projects, see <<package-component#,Package a Component>>. To make it available to others, see <<publish-component#,Publish a Component>>.

To use existing client-side code from Java, pick the guide that matches what you have: a plain <<wrap-js-library#,JavaScript library>>, a <<wrap-web-component#,web component>>, or a <<wrap-react-component#,React component>>.

If you're new to components, read <<../ui-basics/compose#,Compose with Components>> first.
