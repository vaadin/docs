= Forms & Data

Most business applications revolve around data. Users look it up in grids, edit it in forms, and expect their changes to be saved. These guides show how to do this in a Vaadin application.

For the user interface, start with <<add-form#,Add a Form>> and <<add-grid#,Add a Grid>>. To store the data, see <<persistence#,Persistence>>, and <<persistence/replace-h2#,Replace H2>> for switching to a production database. The other guides cover custom fields, file uploads and downloads, and PDF reports.

The forms and grids load and save data through <<../business-logic/add-service#,application services>>. The <<consistency#,Data Consistency>> deep dive explains the reasoning behind this, and covers transactions, locking, and validation.
