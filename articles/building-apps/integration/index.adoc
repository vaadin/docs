= Integration

A Vaadin application doesn't need a REST API for its own user interface. Flow views call application services directly on the server, and <<../react#,React views>> call them through browser-callable services. You need a REST API when other systems have to access the data of your application.

<<rest-api#,REST API Alongside Vaadin>> shows how to expose REST endpoints, either from a separate artifact or from the same module as your views. It also shows how to configure security so that the endpoints and the views can coexist.

When your application calls other systems, make the calls from <<../business-logic/add-service#,application services>>. This keeps the integration out of your views, like the rest of the application layer.
