= Business Logic

In a Vaadin application, views don't implement business logic themselves. They call _application services_, which carry out business operations, and define the transaction and security boundaries around them. For the reasoning behind this, see <<../architecture/layers#,Conceptual Layers>>.

Start with <<add-service#,Add a Service>>, which shows how to design an application service and call it from a view. The <<background-jobs#,Background Jobs>> deep dive covers work that runs outside the request of a user, such as long-running operations, scheduled jobs, and follow-up work triggered by events.

To store data, see <<../forms-data/persistence#,Persistence>>. To protect services from unauthorized calls, see <<../security/protect-services#,Protect Services>>.
