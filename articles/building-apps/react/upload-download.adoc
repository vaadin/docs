= Upload and Download Files
:toclevels: 2

This guide shows how to upload files from a React view with the <<{articles}/components/upload#,Upload>> component, and how to let users download them. Both go through a Spring controller: the Upload component sends each file in a request of its own, and a browser downloads a file from a URL.

The [methodname]`upload()` method returns the ID of the file as the response text. The [methodname]`download()` method sends the file with a `Content-Disposition` header, which makes the browser save it under its original name. [classname]`ContentDisposition` encodes names that contain other than ASCII characters.

Keep the controller's path apart from the routes of your views, for example under `/api`. That way, the security rule for the controller doesn't apply to a view.


== Allowing Access to the Controller

Vaadin's security configuration denies the requests that no rule allows, so add a rule for the controller. The following rule lets logged-in users upload and download files:

[source,java]
----
@Bean
SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
    http.authorizeHttpRequests(auth -> auth
            .requestMatchers("/api/files/**").authenticated());
    http.with(VaadinSecurityConfigurer.vaadin(), configurer -> {
        configurer.loginView("/login");
    });
    return http.build();
}
----

For the other options, see <<{articles}/flow/security/spring/security-configuration#,Security Configuration>> in the reference.

=== Limiting the File Size

Spring Boot accepts files of up to 1 MB by default. For a larger file, the server answers with status 413, and the Upload component shows that the file is too large. To accept larger files, set the limits in [filename]`application.properties`:

[source,properties]
----
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB
----

To reject a large file before it's uploaded, also set the `maxFileSize` property of the Upload component, in bytes.
