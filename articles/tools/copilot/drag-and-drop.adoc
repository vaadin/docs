= Move Components with Drag & Drop

Rearrange a view by dragging its components, in the view itself or in the Outline. Copilot moves the lines of code that add them.

include::_walkthrough-drag-and-drop.adoc[]


== Where a Component Goes

While you drag, drop zones show where the component can go. In a form layout, the drop zone before a field is a narrow strip at the field's left edge. When the drop zone you want is hard to hit, drag in the Outline instead.
