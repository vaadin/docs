= Go to Source

Every component in the running application is created somewhere in your code. Copilot opens that line in your IDE.

include::_walkthrough-go-to-source.adoc[]


== Shortcuts

Select a component and press kbd:[Ctrl+B] to open the line that creates it, or kbd:[Ctrl+Shift+B] to open the line that adds it to the view.

For the best experience, use the Vaadin plugin for your IDE. See <<index#ide-integration,IDE Integration>>.
