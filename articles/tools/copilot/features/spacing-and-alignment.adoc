= Spacing & Alignment

A layout's badge has switches for its padding and for the gap between its components, and a button for its alignment. Copilot writes the change to your Java code.

include::_walkthrough-spacing-and-alignment.adoc[]


== More Options

*Alignment* also has *Justify*, which places the components along the layout's direction, and *Wrap*, which lets them continue on a new row or column.
