= Impersonate Users

In an application with a login, see it as any of its users: switch to a user by name, without a password. It's good for checking what each role may see and do, such as which views are in the menu.

include::_walkthrough-impersonate-users.adoc[]


== What It Needs

Impersonation works in applications that use Spring Security, as set up in <<{articles}/building-apps/security/add-login#,Add Login>>. Copilot looks the username up with your application's [interfacename]`UserDetailsService`, and signs you in with that user's roles. Without Spring Security, the panel says that it's disabled.

Like the rest of Copilot, it's only there in development mode.
