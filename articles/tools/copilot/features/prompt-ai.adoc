= Prompt AI to Make Changes

Select something and say what you want changed, in your own words. Copilot's AI changes the code, and the view updates. It's good for changes that touch many components at once, or that you'd otherwise look up.

.Before You Start
[NOTE]
The AI needs you to be logged in with a Vaadin account, and to allow Copilot to use AI.

== The Answers Vary

The AI doesn't answer the same request the same way twice. Check the result in the view and in the code, and ask again in other words when it's not what you meant. The more specific the request, the closer the result.
