= Copy, Paste, Duplicate & Delete

A component's menu has what you'd expect of any editor: copy, paste, duplicate, and delete. Each changes the code.

include::_walkthrough-copy-and-paste.adoc[]


== Keyboard Shortcuts

[cols="1,1,2"]
|===
|Windows & Linux |macOS |Does

|kbd:[Ctrl+C]
|kbd:[⌘+C]
|Copies the selected component.

|kbd:[Ctrl+V]
|kbd:[⌘+V]
|Pastes after the selected component.

|kbd:[Ctrl+D]
|kbd:[⌘+D]
|Duplicates the selected component.

|kbd:[Delete]
|kbd:[Delete]
|Deletes the selected component.
|===
