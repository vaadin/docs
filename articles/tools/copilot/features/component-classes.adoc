= Extract and Edit Component Classes

A part of a view that you want to reuse, such as a form, can become a component class of its own. Copilot extracts it, and edits inside it: the change goes into its class, and so into every view that uses it.

The new class is inside the view's class. To use it in other views, move it to a file of its own with your IDE's refactoring, such as *Move* in IntelliJ IDEA, and give it a name of its own.

== Which File Copilot Changes

The *Editing* tag names the file that your changes go into. Outside a component class, that's the view's file: changing the component there changes it in that view only. Inside, it's the component's class, and the change shows in every view that uses the component.
