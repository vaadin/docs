== Keyboard Shortcuts

[cols="1,2"]
|===
|Key |Selects

|kbd:[←]
|The parent of the selected component.

|kbd:[↓]
|The first component inside the selected one, then the next one.

|kbd:[↑]
|The component before the selected one.
|===
