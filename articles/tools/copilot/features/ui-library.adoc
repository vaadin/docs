= Add Components from the UI Library

The UI Library has the components and layouts that you can add to a view. Find one, drag it in, and Copilot writes the code that creates and adds it.

include::_walkthrough-ui-library.adoc[]


== Arrange the Library

The pencil next to the search field opens the library's settings. Hide the sections that your team doesn't use, reorder them, or add a section of your own. Copilot saves the settings in the project, in [filename]#vaadin-copilot.json#.
