= The Copilot Toolbar

Copilot is part of your application while it runs in development mode. Open the application in the browser and the toolbar is there.

include::_walkthrough-toolbar.adoc[]


== Modes

*Play*:: Use the application as usual.
*Inspect*:: See the structure of a view, without changing it.
*Edit*:: Change the view: edit text, move components, set properties.
*Test*:: Check accessibility, add annotations and work on tests.

To switch between Play and the mode you used last, hold kbd:[Shift] and press kbd:[Ctrl] twice (kbd:[Cmd] on macOS).

The panels that each mode offers are listed in <<index#built-in-panels,Built-In Panels>>.
