= Reference Guide

This guide documents the framework that you use to build the user interface of a Vaadin application. It describes each feature in full: its API, its configuration options, and how it behaves. For step-by-step instructions on common tasks, see <<{articles}/building-apps#,Building Apps>> instead.

A Vaadin application builds its user interface from views of two kinds:

* *Flow views* are written in Java, from UI components, and run on the server. Flow is the part of Vaadin that runs them, and most of this guide documents it.
* *React views* are written in React and TypeScript, and run in the browser. They call Java code on the server through browser-callable services. See <<react-views#,React Views>>.

Both kinds of views can be in the same application. To learn how each kind works, start with <<how-vaadin-works#,How Vaadin Works>>.
