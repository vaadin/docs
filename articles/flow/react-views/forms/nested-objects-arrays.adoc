[[nested-objects]]
== Nested Objects

The model of an object property has models for the properties of the object, so a field can bind to them directly, such as `field(model.address.street)`. The name of the field is the path of the property, `address.street`. The errors of the server use the same path, so that they appear in the right field.

To split a form into components, pass the model of a nested object to a component, and call [methodname]`useFormPart()` there. The part has a [methodname]`field()` function of its own, and the state of the nested object, as described in <<form-state#,Form State>>. == Arrays

To add or remove items, call [methodname]`setValue()` with a new list. The default value of a model, such as `PhoneNumberModel[$defaultValue]`, is an empty item. Import `$defaultValue` from `@vaadin/hilla-models`:

[source,tsx]
----
include::{root}/frontend/demo/fusion/forms/person/person-details-form.tsx[tags=snippet,indent=0]
----

The models in `items` follow the positions in the list, so use the index as the key. The name of a field in an item contains the index, such as `phoneNumbers.0.number`.
