= Field Components

The [methodname]`field()` function binds the following Vaadin components. Each component edits a property of one of the listed Java types:

[cols="2,3"]
|===
|Component |Java type of the property

|<<{articles}/components/text-field#,Text Field>>, <<{articles}/components/text-area#,Text Area>>, <<{articles}/components/password-field#,Password Field>>, <<{articles}/components/email-field#,Email Field>>
|`String`

|<<{articles}/components/number-field#,Integer Field, Number Field>>
|A number type, such as `int`, `Integer`, `double`, or `BigDecimal`

|<<{articles}/components/checkbox#,Checkbox>>
|`boolean`

|<<{articles}/components/date-picker#,Date Picker>>
|`LocalDate`

|<<{articles}/components/time-picker#,Time Picker>>
|`LocalTime`

|<<{articles}/components/date-time-picker#,Date Time Picker>>
|`LocalDateTime`

|<<{articles}/components/select#,Select>>, <<{articles}/components/radio-button#,Radio Button Group>>
|`String` or an enum, matched to the values of the items

|<<{articles}/components/combo-box#,Combo Box>>
|`String` or an enum, matched to the values of the items, or an object, which is the selected item

|<<{articles}/components/checkbox#,Checkbox Group>>
|A list or a set of `String`

|<<{articles}/components/multi-select-combo-box#,Multi-Select Combo Box>>
|A list or a set of the items
|===

For example, a combo box can edit a `Country` property of a form, when its items are `Country` objects:

[source,tsx]
----
<ComboBox label="Country" items={countries} itemLabelPath="name" itemValuePath="name" {...field(model.country)} />
----

See <<form-state#changing-values,Changing Values from Code>> for the whole example.

When the user empties a number field, the value of a nullable number becomes `undefined`. A non-nullable number becomes `NaN`, and the field shows the error "must be a number".

The [methodname]`field()` function throws an error for a component that isn't a field, such as a <<{articles}/components/list-box#,List Box>>. It doesn't read the state of a <<{articles}/components/switch#,Switch>>, so use a checkbox for a `boolean` property instead.
