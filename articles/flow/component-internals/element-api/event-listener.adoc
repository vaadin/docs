= Listening to Element Events

The Element API contains methods to receive events and event data from the browser and handle them on the server side.


== Registering Event Listeners

Use the [methodname]`Element.addEventListener()` method to listen to any browser event.

.Using the [methodname]`addEventListener()` method to react to a `click` event
[example]
====
[source,java]
----
Element helloButton = ElementFactory.createButton("Say hello");
helloButton.addEventListener("click", e -> { // <1>
    Element response = ElementFactory.createDiv("Hello!");
    getElement().appendChild(response); // <2>
});
getElement().appendChild(helloButton);
----
<1> Clicking the "Say hello" button in the browser sends the event to the server for processing.
<2> A new `<div>Hello!</div>` element is added to the DOM.
====

== Accessing Data from Events

You can get more information about the element or user interaction by declaring the required event data and adding it to the [classname]`DomListenerRegistration` returned by the [methodname]`addEventListener()` method.

Declare each value as a method that returns [classname]`DomEventData` in a [annotationname]`@JsDefinition` interface that extends [interfacename]`JsSnippets`. The [annotationname]`@JsExpression` of the method is the body of a function that gets the DOM `event` and the `element` the listener is added to, and returns the value to send.

.Declaring event data and reading it in the listener
[example]
====
[source,java]
----
@JsDefinition
public interface ButtonEventsJs extends JsSnippets {

    @JsExpression("return event.shiftKey;")
    DomEventData<Boolean> shiftKey();

    @JsExpression("return element.offsetWidth;")
    DomEventData<Double> width();
}

private static final ButtonEventsJs JS = JsSnippets.of(ButtonEventsJs.class);

private void addHelloButtonListener(Element helloButton) {
    DomEventData<Boolean> shiftKey = JS.shiftKey();
    DomEventData<Double> width = JS.width();

    helloButton.addEventListener("click", event -> {
        boolean shiftPressed = event.getEventData(shiftKey); // <1>
        double buttonWidth = event.getEventData(width);

        String text = "Shift " + (shiftPressed ? "down" : "up");
        text += " on button whose width is " + buttonWidth + "px";
        getElement().appendChild(ElementFactory.createDiv(text));
    }).addEventData(shiftKey) // <2>
            .addEventData(width);
}
----
<1> [methodname]`DomEvent.getEventData()` returns the value with the type the method declares.
<2> The browser sends the value of each added event data together with the event.
====

The build adds the declared expressions to the frontend bundle, so the browser doesn't compile anything from a string, and the event data also works under a Content Security Policy that doesn't allow `unsafe-eval`. See <<calling-javascript#declaring-snippets,Declaring Snippets>> for more about [interfacename]`JsSnippets` interfaces.


== Filtering and Debouncing

Filtering and debouncing are covered in detail in <<../events#limiting-event-frequency,Declaring and Firing Component Events>>, in the context of the `@DomEvent` annotation. However, you can configure the exact same settings through the [classname]`DomListenerRegistration` object.

To filter events, declare the filter as a method that returns [classname]`DomEventFilter` in a [interfacename]`JsSnippets` interface, and pass what the method returns to [methodname]`setFilterExpression()`. The expression gets the same `event` and `element` parameters as event data, and returns `true` for the events to send to the server.

.Declaring a filter and using it with [methodname]`setFilterExpression()`
[example]
====
[source,java]
----
@JsDefinition
public interface KeyFiltersJs extends JsSnippets {

    @JsExpression("return event.key === $0;") // <1>
    DomEventFilter isKey(String key);
}

private static final KeyFiltersJs FILTERS = JsSnippets.of(KeyFiltersJs.class);

private void addSubmitOnEnter(Element field) {
    field.addEventListener("keydown", event -> submit())
            .setFilterExpression(FILTERS.isKey("Enter"));
}
----
<1> The arguments of the method call are available to the expression as `$0`, `$1`, and so on.
====
