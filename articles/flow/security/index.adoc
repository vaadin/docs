= Security

This section is the reference for securing a Vaadin Flow application: authenticating users, controlling which views they can access, and the protections that Flow provides against common attacks. For task-oriented guides that build on it, see <<{articles}/building-apps/security#,Building Apps > Security>>.

Flow works with the common security frameworks of the Java ecosystem, such as Spring Security, Java Authentication and Authorization Service (JAAS), and Apache Shiro. Its built-in security helpers are mainly intended to be used with Spring Security, but some of them, such as view access control, also work in plain servlet applications.
