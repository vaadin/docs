= Security

Vaadin Flow is a server-side framework: the application state, the business logic, and the UI logic stay on the server. The browser receives only what the application sets on UI components. Internals, such as entity objects or hashed passwords, never reach the browser unless the application puts them into a component. For how Flow handles user interactions, see <<{articles}/building-apps/architecture/runtime-model#,How Vaadin Works at Runtime>>.

This section is the reference for the security features of Flow. For task-oriented guides that build on them, see <<{articles}/building-apps/security#,Building Apps > Security>>.

Flow works with the common security frameworks of the Java ecosystem, such as Spring Security, Java Authentication and Authorization Service (JAAS), and Apache Shiro. Its built-in security helpers -- view access control, and the integration of log-in and log-out -- are designed for Spring Security, but view access control also works without it.
