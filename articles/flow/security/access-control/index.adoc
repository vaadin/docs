= View Access Control

View access control decides whether the current user may navigate to a view. It works the same way in Spring applications and in plain servlet applications, and is the foundation that the setup pages of both build on.

Vaadin provides the following tools for it:

- <<navigation-access-control#,Navigation access control>> checks every navigation against a set of rules, and redirects users who aren't logged in to the log-in view.
- <<annotations#,Access annotations>> on view classes, such as [annotationname]`@RolesAllowed`, are the most common way to define the rules.
- Custom access checkers define rules of your own, for example based on the data that a view shows. See <<navigation-access-control#custom-navigation-access-checker,Custom Navigation Access Checker>>.
- <<error-views#,Error views>> define what users see when navigation is denied.
