= Plain Servlet Applications

Vaadin's view access control also works without Spring. It relies on the user principal and the roles of the servlet request, so it works with any authentication mechanism that sets them: the application's own user store, or servlet container authentication. For Spring Boot applications that don't use Spring Security, see <<../spring/without-spring-security#,Without Spring Security>>.
