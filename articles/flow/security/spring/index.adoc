= Spring Applications

Vaadin's built-in security helpers are designed to be used with Spring Security. In a Spring Boot application, [classname]`VaadinSecurityConfigurer` applies the Spring Security configuration that a Vaadin application needs, and enables view-based access control.

For task-oriented guides that build on these features, see <<{articles}/building-apps/security#,Building Apps > Security>>.
