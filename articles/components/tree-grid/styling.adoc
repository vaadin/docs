= Tree Grid Styling

include::../_styling-section-intros.adoc[tag=selectors]


Root element:: `vaadin-grid`


=== Parent Rows

Collapsed parent row:: `vaadin-grid+++<wbr>+++**::part(collapsed-row)**`
Collapsed parent row cell:: `vaadin-grid+++<wbr>+++**::part(collapsed-row-cell)**`
Expanded parent row:: `vaadin-grid+++<wbr>+++**::part(expanded-row)**`
Expanded parent row cell:: `vaadin-grid+++<wbr>+++**::part(expanded-row-cell)**`

=== Hierarchy Cells

Cell content element:: `vaadin-grid-tree-toggle`
Expanded:: `vaadin-grid-tree-toggle+++<wbr>+++**[expanded]**`
Toggle button:: `vaadin-grid-tree-toggle+++<wbr>+++**::part(toggle)**`

=== More Properties and Selectors
See <<../grid/styling#,Grid>> for more style properties and CSS selectors.


== Highlighting a Subtree [badge-flow]#Flow#

Custom part names can depend on the position of an item in the hierarchy. In the example below, selecting a row highlights all of its descendants with a `selected-subtree` part name. The part name generator checks whether the selected item is an ancestor of the rendered item. Because part names are generated only when a row is rendered, the selection listener refreshes the descendants of both the previously and the newly selected item.
