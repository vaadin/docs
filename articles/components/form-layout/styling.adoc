=== Side Labels

The following style properties and Flow methods can be used to customize the width of labels, the spacing between them and the fields, and [since:com.vaadin:vaadin@V25.4]#their alignment# in label-aside mode:

[cols="2,3,2"]
|===
| Feature | CSS Property | Flow API

|Side label width
|`--vaadin-form-layout-label-width`
|`setLabelWidth`

|Spacing between side label and field
|`--vaadin-form-layout-label-spacing`
|`setLabelSpacing`

|Side label alignment
|`--vaadin-form-layout-label-text-align`
|`setLabelTextAlign`
|===

|Aura, Lumo

|`--vaadin-input-field-label-font-size`
