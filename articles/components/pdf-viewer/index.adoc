== Document Source

The viewer loads the document from a URL that the browser fetches, so the URL must be reachable from the client. In Flow, a file stored on the server, a classpath resource, or a document generated by the application can be served to the browser with a download handler, which provides a generated URL.

[.example]
--
ifdef::flow[]
[source,java]
----
PdfViewer viewer = new PdfViewer("/files/report.pdf");

// Or serve the document from the application:
// a resource on the classpath
viewer.setSrc(DownloadHandler.forClassResource(getClass(),
        "/documents/report.pdf", "report.pdf"));

// a file on the server's file system
viewer.setSrc(DownloadHandler.forFile(new File("/data/report.pdf")));

// a document generated in memory
viewer.setSrc(DownloadHandler.fromInputStream(event -> {
    byte[] pdf = createReport();
    return new DownloadResponse(new ByteArrayInputStream(pdf),
            "report.pdf", "application/pdf", pdf.length);
}));
----
endif::[]

ifdef::lit[]
[source,html]
----
<vaadin-pdf-viewer src="/files/report.pdf"></vaadin-pdf-viewer>
----
endif::[]

ifdef::react[]
[source,tsx]
----
<PdfViewer src="/files/report.pdf" />
----
endif::[]
--

ifdef::flow[]
See <<{articles}/flow/advanced/downloads#,Downloads>> for more about download handlers.
endif::[]

ifdef::lit,react[]
In Lit and React, make the document available at a URL, for example as a static file of the application or from a server route, such as a Spring `@GetMapping` controller method, that writes the PDF to the response.
endif::[]

The viewer fetches the whole document with a single GET request, without range requests. A new source replaces the current document, and the viewer shows its first page.

[NOTE]
A URL on another origin works only if its server allows the request with https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS[Cross-Origin Resource Sharing (CORS)] headers.

=== File Name

The viewer shows the file name in the header and uses it for the downloaded file. By default, the file name comes from the `Content-Disposition` header of the response set by a Flow download handler, or else from the end of the URL path. The file name can also be set explicitly:

[.example]
--
ifdef::flow[]
[source,java]
----
viewer.setFileName("annual-report.pdf");
----
endif::[]

ifdef::lit[]
[source,html]
----
<vaadin-pdf-viewer src="/files/report.pdf" file-name="annual-report.pdf"></vaadin-pdf-viewer>
----
endif::[]

ifdef::react[]
[source,tsx]
----
<PdfViewer src="/files/report.pdf" fileName="annual-report.pdf" />
----
endif::[]
--

== Download

The download button of the toolbar saves the document with its original bytes, so digital signatures stay intact. The viewer does not request the document again for the download.

The download button can be hidden, and the download can be started from the application instead. If the document is still loading, the download starts once it has loaded.

[.example]
--
ifdef::flow[]
[source,java]
----
viewer.setDownloadButtonVisible(false);

// Start the download, for example from a button
viewer.download();
----
endif::[]

ifdef::lit[]
[source,typescript]
----
viewer.downloadButtonHidden = true;

// Start the download, for example from a button
viewer.download();
----
endif::[]

ifdef::react[]
[source,tsx]
----
<PdfViewer ref={viewer} src="/files/report.pdf" downloadButtonHidden />

// Start the download, for example from a button
viewer.current?.download();
----
endif::[]

== Loading & Errors

The viewer notifies the application when a document has loaded, with the page count and the title of the document. It also notifies the application when a document cannot be loaded, with the reason:

- `network`: the document could not be fetched.
- `invalid`: the file is not a valid PDF document.
- `password`: the document is protected with a password.

[.example]
--
ifdef::flow[]
[source,java]
----
viewer.addDocumentLoadListener(event ->
        Notification.show("Loaded " + event.getPageCount() + " pages"));

viewer.addDocumentErrorListener(event -> {
    if (event.getReason() == DocumentErrorReason.PASSWORD) {
        Notification.show("The document is protected with a password");
    }
});
----
endif::[]

ifdef::lit[]
[source,html]
----
<vaadin-pdf-viewer
  src="/files/report.pdf"
  @document-load="${(event: PdfViewerDocumentLoadEvent) => {
    Notification.show(`Loaded ${event.detail.pageCount} pages`);
  }}"
  @document-error="${(event: PdfViewerDocumentErrorEvent) => {
    if (event.detail.reason === 'password') {
      Notification.show('The document is protected with a password');
    }
  }}"
></vaadin-pdf-viewer>
----
endif::[]

ifdef::react[]
[source,tsx]
----
<PdfViewer
  src="/files/report.pdf"
  onDocumentLoad={(event) => {
    Notification.show(`Loaded ${event.detail.pageCount} pages`);
  }}
  onDocumentError={(event) => {
    if (event.detail.reason === 'password') {
      Notification.show('The document is protected with a password');
    }
  }}
/>
----
endif::[]
--

The viewer renders the pages with the pdf.js library, which runs in a web worker. If the application has a Content Security Policy, its `worker-src` directive has to allow the worker script.


== Accessibility

Each page has a text layer over its image. Users can select the text, and screen readers read it. The viewer keeps the text layer only for the pages near the view. Therefore, screen readers reach only the text of these pages.

Links in the document are focusable. A link to another page of the document scrolls to that page. Links with the `http:`, `https:`, and `mailto:` schemes open in a new tab.

A tagged PDF describes the structure of its content, such as headings, lists, tables, and figures. The viewer passes this structure to screen readers.

=== Keyboard Usage

The page area is focusable once a document has loaded. The following shortcuts work while the focus is in the viewer:

[cols="1,2"]
|===
| Keys | Action

|kbd:[Ctrl+Plus] or kbd:[Cmd+Plus]
|Zooms in.

|kbd:[Ctrl+Minus] or kbd:[Cmd+Minus]
|Zooms out.

|kbd:[Ctrl+0] or kbd:[Cmd+0]
|Fits the page width to the viewer.

|kbd:[Ctrl+Home] or kbd:[Cmd+Home]
|Goes to the first page, while the page area has focus.

|kbd:[Ctrl+End] or kbd:[Cmd+End]
|Goes to the last page, while the page area has focus.
|===


[[i18n]]
== Internationalization (i18n)

The texts of the viewer can be localized, such as the tooltips of the toolbar buttons and the zoom options.
Set only the texts that you want to change. The defaults apply to the others.

[.example]
--
ifdef::flow[]
[source,java]
----
viewer.setI18n(new PdfViewerI18n()
        .setPreviousPage("Edellinen sivu")
        .setNextPage("Seuraava sivu")
        .setDownload("Lataa"));
----
endif::[]

ifdef::lit[]
[source,typescript]
----
viewer.i18n = {
  previousPage: 'Edellinen sivu',
  nextPage: 'Seuraava sivu',
  download: 'Lataa',
};
----
endif::[]

ifdef::react[]
[source,tsx]
----
<PdfViewer
  src="/files/report.pdf"
  i18n={{
    previousPage: 'Edellinen sivu',
    nextPage: 'Seuraava sivu',
    download: 'Lataa',
  }}
/>
----
endif::[]
--

Some texts have a placeholder, such as `\{page}`, that the viewer replaces with a value. The Flow [classname]`PdfViewerI18n` class has the following texts. Lit and React have the `page`, `zoom`, `pageLabel` and `loading` texts in addition.

[cols="1,2"]
|===
| Text | Default value

|`previousPage`
|Previous page

|`nextPage`
|Next page

|`pageError`
|Enter 1–\{pageCount}

|`zoomIn`
|Zoom in

|`zoomOut`
|Zoom out

|`pageWidth`
|Page width

|`pageFit`
|Page fit

|`document`
|PDF document

|`link`
|Link

|`goToPage`
|Go to page \{page}

|`externalLink`
|\{text} (opens in a new tab)

|`download`
|Download
|===
