Root element:: `vaadin-pdf-viewer`


=== States

Loading a document:: `vaadin-pdf-viewer+++<wbr>+++**[loading]**`
Document failed to load:: `vaadin-pdf-viewer+++<wbr>+++**[has-error]**`
Page area focused:: `vaadin-pdf-viewer+++<wbr>+++**[focused]**`
Page area keyboard focused:: `vaadin-pdf-viewer+++<wbr>+++**[focus-ring]**`


=== Header

Header:: `vaadin-pdf-viewer+++<wbr>+++**::part(header)**`
Title:: `vaadin-pdf-viewer+++<wbr>+++**::part(title)**`
Collapse and expand icon:: `vaadin-pdf-viewer+++<wbr>+++**::part(header-toggle)**`


=== Toolbar

Toolbar:: `vaadin-pdf-viewer+++<wbr>+++**::part(toolbar)**`
Group of related controls:: `vaadin-pdf-viewer+++<wbr>+++**::part(toolbar-group)**`

Each control of the toolbar has a slot of its own. The controls are Vaadin components: the buttons are Button components, the page field is an Integer Field, and the zoom select is a Select. Style them as you style these components.

Previous page button:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-previous-page"]**`
Next page button:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-next-page"]**`
Page field:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-page"]**`
Zoom out button:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-zoom-out"]**`
Zoom select:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-zoom"]**`
Zoom in button:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-zoom-in"]**`
Download button:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-download"]**`
Toolbar actions:: `vaadin-pdf-viewer+++<wbr>+++** > [slot="toolbar-actions"]**`

In Flow, the toolbar actions are inside a container element in the `toolbar-actions` slot. To target the actions themselves, use `vaadin-pdf-viewer > [slot="toolbar-actions"] > *`.


=== Pages

Scrollable page area:: `vaadin-pdf-viewer+++<wbr>+++**::part(content)**`
Page:: `vaadin-pdf-viewer+++<wbr>+++**::part(page)**`
Loading indicator:: `vaadin-pdf-viewer+++<wbr>+++**::part(loader)**`
