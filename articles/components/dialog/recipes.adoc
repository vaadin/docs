== Keyboard Shortcuts [badge-flow]#Flow#

Modal dialogs close when the user presses kbd:[Escape]. You can turn this off with `setCloseOnEsc(false)`, for example when closing would discard unsaved input.

To let kbd:[Enter] submit the dialog, add a click shortcut to the primary button and scope it to the dialog. When a footer button has focus, kbd:[Enter] activates that button, so stop the key event there to avoid triggering the primary action as well:

[source,java]
----
saveButton.addClickShortcut(Key.ENTER).listenOn(dialog); // <1>

Shortcuts.addShortcutListener(dialog, () -> {}, Key.ENTER)
        .listenOn(cancelButton, saveButton) // <2>
        .allowBrowserDefault();
----
<1> kbd:[Enter] clicks the Save button while focus is anywhere inside the dialog.
<2> kbd:[Enter] on a focused footer button only activates that button. Shortcuts stop the event from propagating by default, and `allowBrowserDefault()` keeps the button's own kbd:[Enter] handling.

See <<{articles}/building-apps/ui-basics/add-keyboard-shortcuts#,Add Keyboard Shortcuts>> for more about shortcuts.
