include::../_styling-section-theming-props.adoc[tag=overlay-animation]

For example, the following makes dialogs with the `slide-in` class name fade in while sliding up a short distance when opened, and fade out while sliding back down when closed. The animation timing comes from the theme:

[source,css]
----
vaadin-dialog.slide-in {
  --vaadin-overlay-translate-closed: 0 2rem;
  --vaadin-overlay-scale-closed: 1;
}
----

Lumo uses its own Dialog animation, which these properties don't affect. With Lumo, replace the built-in overlay animation in the `opening` and `closing` states with keyframes that combine the same fade with a slide. Using the same durations, delays, and easing curves as the built-in animation keeps it in sync with the backdrop fade and the timing Lumo expects before the dialog is removed:

[source,css]
----
vaadin-dialog.slide-in[opening]::part(overlay) {
  animation: 0.12s 0.05s slide-in-enter cubic-bezier(0.215, 0.61, 0.355, 1) both;
}

vaadin-dialog.slide-in[closing]::part(overlay) {
  animation: 0.1s 0.03s slide-in-exit cubic-bezier(0.55, 0.055, 0.675, 0.19) both;
}

@keyframes slide-in-enter {
  from {
    opacity: 0;
    translate: 0 2rem;
  }
}

@keyframes slide-in-exit {
  to {
    opacity: 0;
    translate: 0 2rem;
  }
}
----

Root element:: `vaadin-dialog`


=== States

Non-modal:: `vaadin-dialog+++<wbr>+++**[modeless]**`
Dialog with header:: `vaadin-dialog+++<wbr>+++**[has-header]**`
Dialog with footer:: `vaadin-dialog+++<wbr>+++**[has-footer]**`
Resizable:: `vaadin-dialog+++<wbr>+++**[resizable]**`
Draggable:: `vaadin-dialog+++<wbr>+++**[draggable]**`


=== Parts

Modality curtain (backdrop):: `vaadin-dialog+++<wbr>+++**::part(backdrop)**`
Dialog surface:: `vaadin-dialog+++<wbr>+++**::part(overlay)**`
Header:: `vaadin-dialog+++<wbr>+++**::part(header)**`
Title wrapper:: `vaadin-dialog+++<wbr>+++**::part(title)**`
Title element:: `vaadin-dialog+++<wbr>+++** > [slot="title"]**`
Header custom content wrapper:: `vaadin-dialog+++<wbr>+++**::part(header-content)**`
Content area:: `vaadin-dialog+++<wbr>+++**::part(content)**`
Footer:: `vaadin-dialog+++<wbr>+++**::part(footer)**`
