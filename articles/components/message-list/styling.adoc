= Message List Styling


[role="since:com.vaadin:vaadin@V25.3"]
== Style Variants

The following style variants are supported by Message List:

[cols="1,3,1"]
|===
| Variant | Description | Supported by

|`bubble`
|Shows the messages as chat bubbles
|Aura, Lumo

|`one-to-one`
|Hides the avatars and names of all messages, for a conversation between two participants. Takes effect only together with `bubble`.
|Aura, Lumo

|===

The following style variants are supported by individual messages. They take effect only when the list uses the `bubble` variant:

[cols="1,3,1"]
|===
| Variant | Description | Supported by

|`self`
|Shows the message as sent by the current user: aligned to the end, tinted with the user color, and without the avatar and name
|Aura, Lumo

|`full-width`
|Removes the bubble and the width restriction, for example for the responses of an AI assistant
|Aura, Lumo

|===

The message variants are applied to the items, not to the list: in Flow with [methodname]`addThemeVariants()` on [classname]`MessageListItem` and the [classname]`MessageListItemVariant` constants, and in Lit and React with the `theme` property of an item.


=== Chat Bubbles

The `bubble` variant shows each message in a bubble that fits its content, with the avatar next to it. Apply the `self` variant to the messages of the current user. Their bubbles are aligned to the end of the list and tinted with the user color, which is the same color that the user color index gives the avatar. The variant also hides the avatar and name, but screen readers still announce the name.

=== One-to-One Conversations

In a conversation between two participants, such as a chat with an AI assistant, the position of a message already tells who sent it. The `one-to-one` variant hides the avatars and names of all messages, while the `self` variant keeps the messages of the current user aligned to the end. As with the `self` variant, screen readers still announce the names.

The `full-width` variant removes the bubble and the width restriction from a message. Use it for the responses of an AI assistant, which are often long and formatted with <<index#markdown,Markdown>>.

=== List

Root element:: `vaadin-message-list`
Internal list layout:: `vaadin-message-list+++<wbr>+++**::part(list)**`

=== Message

Root element:: `vaadin-message`
Focused message:: `vaadin-message+++<wbr>+++**[focused]**`
Keyboard focused message:: `vaadin-message+++<wbr>+++**[focus-ring]**`
Text content layout:: `vaadin-message+++<wbr>+++**::part(content)**`
Header row:: `vaadin-message+++<wbr>+++**::part(header)**`
Name:: `vaadin-message+++<wbr>+++**::part(name)**`
Timestamp:: `vaadin-message+++<wbr>+++**::part(time)**`
Message text:: `vaadin-message+++<wbr>+++**::part(message)**`

==== Attachments

Attachments container:: `vaadin-message+++<wbr>+++**::part(attachments)**`
Attachment button:: `vaadin-message+++<wbr>+++**::part(attachment)**`
Image attachment button:: `vaadin-message+++<wbr>+++**::part(attachment attachment-image)**`
File attachment button:: `vaadin-message+++<wbr>+++**::part(attachment attachment-file)**`
Image thumbnail:: `vaadin-message+++<wbr>+++**::part(attachment-preview)**`
File icon:: `vaadin-message+++<wbr>+++**::part(attachment-icon)**`
File name:: `vaadin-message+++<wbr>+++**::part(attachment-name)**`


==== Avatars

Avatar:: `vaadin-message+++<wbr>+++** > vaadin-avatar**`
Avatar icon:: `vaadin-message+++<wbr>+++** > vaadin-avatar::part(icon)**`
Avatar abbreviation:: `vaadin-message+++<wbr>+++** > vaadin-avatar::part(abbr)**`
