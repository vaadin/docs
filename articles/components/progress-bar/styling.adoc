= Progress Bar Styling

== Style Variants

Progress Bar supports the following style variants.

[cols="1,3,1"]
|===
|Variant | Description | Supported by

| `success`
| When progress is satisfactory and/or nearing completion

| Lumo

| `error`
| When progress is unsatisfactory or draw the user's attention to a stalled or failed process
| Lumo

| `contrast`
| Improved visibility
| Lumo

|===


include::../_styling-section-theming-props.adoc[tag=style-properties]

[cols="3,1"]
|===

| Property | Supported by

| `--vaadin-progress-bar-animation-duration`
| Aura

| `--vaadin-progress-bar-background`
| Aura

| `--vaadin-progress-bar-border-color`
| Aura

| `--vaadin-progress-bar-border-radius`
| Aura

| `--vaadin-progress-bar-border-width`
| Aura

| `--vaadin-progress-bar-height`
| Aura

| `--vaadin-progress-bar-padding`
| Aura

| `--vaadin-progress-bar-value-background`
| Aura

|===

To change the color of a single Progress Bar at runtime, for example based on its value, set the property as an inline style on that instance. The Lumo theme doesn't support the property, but uses the primary color of the theme for the value, which can be overridden for the instance in the same way:

[source,java]
----
progressBar.getStyle()
        .set("--vaadin-progress-bar-value-background", color) // Aura
        .set("--lumo-primary-color", color); // Lumo
----
