= Notification Styling

== Style Variants

Notification supports the following style variants.

[cols="1,3,1"]
|===
| Variant | Description | Supported by

|`success`
|Used to display success messages
|Lumo, Aura

|`warning`
|Used to display warnings
|Lumo, Aura

|`error`
|Used to display errors
|Lumo, Aura

|`info`
|Used for informational messages
|Lumo, Aura

|`contrast`
|Used to distinguish the notification from the rest of the UI
|Lumo

|===

Error notifications should be persistent, and provide the user with a button that closes the notification or allows the user to take appropriate action.

Notifications are non-modal and can be ignored. Therefore, they're usually inappropriate for displaying unexpected technical errors that prevent the application from functioning, or situations that require immediate user action. Use instead a modal <<../dialog#, Dialog>> in such situations.

The built-in error message feature, included with input field components, should be used for field-specific input validation errors.

== Emphasizing Notifications

With the Aura theme, the style variants tint the notification background with a subtle variant color, so that notifications don't overpower the rest of the UI. If a notification needs to stand out more, emphasize it through its content rather than through the background color alone. For example, add an icon, a heading, or a prominent button. See <<index#icons-other-rich-formatting,Icons & Other Rich Formatting>> for an example.

Another option is to use a dark color scheme for notifications, which makes them stand out against a light UI. To apply a dark color scheme to all notifications in the Aura theme, set the `--aura-notification-color-scheme` property. See <<{articles}/styling/themes/aura/color#,Aura Color>> for details.

[source,css]
----
html {
  --aura-notification-color-scheme: dark;
}
----

To apply a dark color scheme to a single notification, add a class name to its notification card:

[.example]
--
[source,java]
----
<source-info group="Flow"></source-info>
notification.addClassName("dark");
----

[source,tsx]
----
<source-info group="React"></source-info>
<Notification overlayClass="dark" />
----

[source,html]
----
<source-info group="Lit"></source-info>
<vaadin-notification overlay-class="dark"></vaadin-notification>
----
--

Then set the color scheme for notification cards with that class name in your stylesheet:

[source,css]
----
vaadin-notification-card.dark {
  color-scheme: dark;
}
----
