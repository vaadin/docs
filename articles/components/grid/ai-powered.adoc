= [since:com.vaadin:vaadin@V25.2]#AI-Powered Grid# [badge-flow]#Flow#

AI-Powered Grid lets your users fill a Vaadin Grid with data by typing in natural language. The [classname]`GridAIController` from the <<{articles}/flow/ai-support#, AI Support>> module wires an [classname]`AIOrchestrator` to a [classname]`Grid` and a <<{articles}/flow/ai-support/controllers#database-provider, [classname]`DatabaseProvider`>>, so an LLM can inspect the database schema and run SQL queries that drive the grid. The grid then renders the result with generated columns and lazy loading.

Enable the <<{articles}/flow/configuration/feature-flags#, feature flag>> before you use the controller:

[source,properties]
----
# Add this line to src/main/resources/vaadin-featureflags.properties
com.vaadin.experimental.aiComponents=true
----

The grid is typed as [classname]`Grid<AIDataRow>`. [classname]`AIDataRow` is a framework-owned row type that the controller fills -- you never construct instances yourself.

The [classname]`JdbcDatabaseProvider` in the example is not a Vaadin class. It's an implementation of the <<{articles}/flow/ai-support/controllers#database-provider, [classname]`DatabaseProvider`>> interface that you write for your application. Back it with a database account that has read-only access, since the LLM writes the SQL that it runs.

[source,java]
----
Grid<AIDataRow> grid = new Grid<>();
MessageInput messageInput = new MessageInput();

DatabaseProvider databaseProvider = new JdbcDatabaseProvider(dataSource);
GridAIController controller = new GridAIController(grid, databaseProvider);

AIOrchestrator.builder(provider, systemPrompt)
        .withInput(messageInput)
        .withController(controller)
        .build();

add(messageInput, grid);
----

Example prompts:

* "Show product name and category grouped under Product, and monthly revenue."
* "List the top 10 highest-paid employees with name, salary, and hire date."
* "List all employees in the Sales department."

For the full guide -- including query validation, state persistence, and reconnecting after deserialization -- see <<{articles}/flow/ai-support/ai-powered-grid#, AI-Powered Grid>> in the AI Support section. The same approach is available for charts via <<{articles}/flow/ai-support/ai-powered-chart#, AI-Powered Chart>>.
