= [since:com.vaadin:vaadin@V25.2]#AI-Powered Grid# [badge-flow]#Flow#

AI-Powered Grid lets your users fill a Vaadin Grid with data by typing in natural language. The [classname]`GridAIController` from the <<{articles}/flow/ai-support#, AI Support>> module wires an [classname]`AIOrchestrator` to a [classname]`Grid` and a [classname]`DatabaseProvider`, so an LLM can inspect the database schema and run SQL queries that drive the grid. The grid then renders the result with generated columns and lazy loading.

:commercial-feature: AI-Powered Grid
include::{articles}/_commercial-banner.adoc[opts=optional]

[source,java]
----
Grid<AIDataRow> grid = new Grid<>();
MessageInput messageInput = new MessageInput();

DatabaseProvider databaseProvider = new JdbcDatabaseProvider(dataSource);
GridAIController controller = new GridAIController(grid, databaseProvider);

AIOrchestrator.builder(provider, systemPrompt)
        .withInput(messageInput)
        .withController(controller)
        .build();

add(messageInput, grid);
----

Example prompts:

* "Show product name and category grouped under Product, and monthly revenue."
* "List the top 10 highest-paid employees with name, salary, and hire date."
* "List all employees in the Sales department."

For the full guide -- including query validation, state persistence, and reconnecting after deserialization -- see <<{articles}/flow/ai-support/ai-powered-grid#, AI-Powered Grid>> in the AI Support section. The same approach is available for charts via <<{articles}/flow/ai-support/ai-powered-chart#, AI-Powered Chart>>.
