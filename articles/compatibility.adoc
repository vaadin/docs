== Browser Compatibility

Vaadin supports current browser versions and moves forward as browsers release new versions. The following lists the desktop and mobile browsers supported by Vaadin 25.3, with the minimum versions as of its release.

=== Desktop Browsers

[cols="1,1"]
|===
| Browser | Version

| Firefox | 157 or later
| Firefox Extended Support Release (ESR) | 140 or later
| Safari | 17.6, 18.6, 26.6, and 27 or later
|===

=== Browser Support Policy

Chrome, Edge, and Firefox are supported as _evergreen_ browsers. This means that the latest versions are supported, since most users update to them soon after they are released. Firefox ESR is supported in the same way: the current ESR version is supported, and so is the earlier one until Mozilla ends its support. Older ESR versions aren't supported, even if they still receive security updates for legacy operating systems.

Apple keeps older Safari major versions available to users who can't upgrade their operating system. Therefore, the latest minor version of each listed Safari major version is supported.

Minimum browser versions aren't raised in maintenance releases. They may be raised in minor and major releases, as browsers release new versions. A new minor release doesn't always raise them, though: they're raised only when there's a reason to do so.

When a browser is too old to run the application, Vaadin shows a page that tells the user to update their browser.
