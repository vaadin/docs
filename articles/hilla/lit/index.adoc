= Lit

This section documents using Hilla with Lit, which is deprecated and is removed in Vaadin 26, together with the `@vaadin/router` library it builds on. Migrate Hilla Lit views to <<{articles}/hilla#, Hilla with React>> before upgrading. See <<{articles}/upgrading#vaadin-router-removal, Vaadin Router Deprecation>> for more information.

[NOTE]
This concerns Hilla only. The https://lit.dev/[Lit] library itself isn't deprecated -- Flow's [classname]`LitTemplate` API and the Lit templates that Vaadin Designer generates aren't affected.
