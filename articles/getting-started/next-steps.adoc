= Expand Your Vaadin Project

You now have a working Vaadin application, built either in the <<tutorial#,Tutorial>> or the <<quick-start#,Quick Start>>. The next step is to turn it into an application that you can put in front of real users. The <<{articles}/building-apps#,Building Apps>> section of the documentation has guides for this. These are the ones most applications need next.


== Build Your User Interface

Learn how to arrange components with layouts, and how sizing works inside them, in the <<{articles}/building-apps/ui-basics/layouts#,Arrange with Layouts>> guide. To change how your application looks, see <<{articles}/building-apps/ui-basics/add-styling#,Add Styling>>. The <<{articles}/building-apps/ui-basics#,UI Basics>> guides cover these and other building blocks, such as dialogs, notifications, and keyboard shortcuts.


== Add Views & Navigation

Expand your application by adding more views, a navigation menu, and ways to pass data between views. See the <<{articles}/building-apps/views#,Views & Navigation>> guides for step-by-step instructions.


== Add Data

Learn more about forms, validation, and grids, and about loading and saving data consistently, by following the <<{articles}/building-apps/forms-data#,Forms & Data>> guides.


== Implement Security

Secure your application with user authentication and authorization. Refer to the <<{articles}/building-apps/security#,Security>> guides to learn how.


== Use a Real Database

The tutorial uses an in-memory H2 database, which loses its data when the application stops. Replace it with a production-ready database, and manage its schema with migrations. Follow the <<{articles}/building-apps/forms-data/persistence/add-flyway#,Add Flyway>> and <<{articles}/building-apps/forms-data/persistence/replace-h2#,Replace H2>> guides for details.


== Test Your Application

Verify that your views behave as intended with browserless tests, which run against your Java components without starting a browser. See the <<{articles}/building-apps/testing#,Testing>> guides to get started.


== Deploy to Production

Build your application for production, and deploy it to a server, a container platform, or the cloud. See <<{articles}/flow/production#,Deploying to Production>> for instructions.


== Use an AI Coding Agent

If you develop with an AI coding agent such as Claude Code or Codex, give it Vaadin's documentation through the <<{articles}/building-apps/agentic-development/mcp#,Vaadin MCP server>>. Then follow the <<{articles}/building-apps/agentic-development/dev-loop-tutorial#,Dev Loop Tutorial>> to let the agent edit your running application and verify its own changes, without restarts or screenshots.
