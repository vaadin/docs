= Set Up an AI Agent

An AI coding agent needs two things that a model doesn't have on its own: the documentation for the Vaadin version your project uses, and a way to find out whether its changes run. This page sets up the first once per machine. It then shows what each project adds for the second. <<{articles}/building-apps/agentic-development#,Agentic Development>> explains the pieces in depth.

You don't need an agent to develop with Vaadin. If you don't use one, skip this page.


== Choose an Agent

Claude Code and Codex get the most complete setup, because the Vaadin Skills plugin installs the documentation server and a set of Vaadin skills for them in one step. Cursor, GitHub Copilot, Gemini CLI, Junie, and Windsurf connect to the documentation server through their own MCP configuration. See <<{articles}/building-apps/agentic-development/mcp/supported-tools#,Supported Tools>> for the list, and install the agent from its vendor the way you would without Vaadin.


== Connect the Agent to Vaadin's Documentation

The Vaadin MCP server searches the documentation and the Java, React, and web component API for the agent, and tells it which Vaadin version is current. The agent then looks things up instead of recalling them from training data that may describe an older Vaadin version.

If you use Claude Code or Codex, install the <<{articles}/building-apps/agentic-development/agent-skills#,Vaadin Skills>> plugin. It configures the MCP server at user level, so every project gets it, and adds skills for generating an Aura theme, giving a view a polished design, and laying out a form:

[.example]
--
[source,terminal]
----
<source-info group="Claude Code"></source-info>
/plugin marketplace add vaadin/agent-marketplace
/plugin install vaadin-skills@vaadin-marketplace
----

[source,terminal]
----
<source-info group="Codex"></source-info>
codex plugin marketplace add vaadin/agent-marketplace --ref main
codex plugin add vaadin-skills@vaadin-marketplace
----
--

In Claude Code, run `/mcp` in a new session to check that the `vaadin` server is connected.

For any other agent, add the server at `https://mcp.vaadin.com/docs` to the agent's MCP configuration. It uses streamable HTTP and needs no authentication. The <<{articles}/building-apps/agentic-development/mcp/supported-tools#,Supported Tools>> guides show the configuration for each agent.

To let the agent search the add-on catalog of the Vaadin Directory as well, add the separate <<{articles}/building-apps/agentic-development/directory-mcp#,Vaadin Directory MCP server>>.


== Set Up a Project for the Agent

A project adds configuration and tooling of its own, which you commit so that every developer and every agent on the repository works the same way:

Project configuration from Vaadin Start::
When you create a project with <<../starters/start#ai-development-tool,Vaadin Start>>, select your agent under *AI Development Tool*. The project then includes the agent's configuration file for the Vaadin MCP server. In an existing project, add the same file by hand, as shown in the Supported Tools guide for your agent.

The dev loop::
The <<{articles}/flow/configuration/live-reload/dev-loop-cli#,Dev Loop CLI>> runs the application under a daemon, and gives the agent one command that makes its edits live and reports whether they took effect. Install it in the project with `mvn vaadin:install-dev-cli`. The goal writes the CLI into [filename]`.vaadin/` and the skills that teach the agent to use it into [filename]`.agents/skills/` and [filename]`.claude/skills/`. The <<run#,Run a Project>> guide covers running the application without it.

Agent Tools::
The experimental <<{articles}/building-apps/agentic-development/agent-tools#,Agent Tools>> plugin for Claude Code and Codex adds commands that scaffold a project from the real starter and check how the project uses the Aura and Lumo themes.


== Vaadin Copilot

<<{articles}/tools/copilot#,Vaadin Copilot>> is a visual development tool that runs in the browser, on top of your application in development mode. It needs no installation. You can inspect and edit the UI in the browser, and use its AI features to make changes. It works next to the coding agent in your terminal or IDE. The IDE guides under <<run#,Run a Project>> use Copilot to check that hotswap works.
