= Development Environment

To develop Vaadin applications, you need a Java Development Kit (JDK) and a Java IDE. If you don't have them yet, this is the fastest path:

. <<install-java#,Install Eclipse Temurin>>, version {vaadin-start-java-version} or newer.
. <<install-ide#,Install IntelliJ IDEA>>. The free Community Edition is enough.
. <<import/intellij#,Open your project in IntelliJ IDEA>> and <<run/intellij#,run it with hotswap>> using the Vaadin plugin.

The pages in this section also cover other JDK distributions, and the Visual Studio Code, Eclipse, and NetBeans IDEs.
