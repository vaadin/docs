= Development Environment

To build a Java application with a Vaadin UI, you need the same tools as for any other Java application: a Java Development Kit (JDK) and a Java IDE. You don't have to install any frontend tools, since Vaadin downloads the ones it needs during the build. If you don't have a JDK and an IDE yet, this is the fastest path:

. <<install-java#,Install Eclipse Temurin>>, version {vaadin-start-java-version} or newer.
. <<install-ide#,Install IntelliJ IDEA>>. You can use it for free, without a subscription.
. <<import/intellij#,Open your project in IntelliJ IDEA>> and <<run/intellij#,run it with hotswap>> using the Vaadin plugin.

The pages in this section also cover other JDK distributions, and the Visual Studio Code, Eclipse, and NetBeans IDEs. For the minimum versions of Java and the other technologies that Vaadin works with, such as Spring Boot, Maven, and application servers, see <<{articles}/compatibility#,Supported Technologies>>.
