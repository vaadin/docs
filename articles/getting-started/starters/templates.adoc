= Create a Project by Cloning a Template

If you prefer a different technology stack than Spring Boot and Maven, you can find _Hello World_ starter templates for other frameworks here:

* https://github.com/vaadin/skeleton-starter-flow[Flow / Java, Maven, and Jetty]
* https://github.com/vaadin/base-starter-flow-quarkus[Flow / Java, Maven, and Quarkus]
* https://github.com/vaadin/skeleton-starter-flow-cdi[Flow / Java, Maven, CDI, and WildFly]
* https://github.com/vaadin/base-starter-spring-gradle[Flow / Java, Gradle, and Spring Boot]
* https://github.com/vaadin/skeleton-starter-kotlin-spring[Flow / Kotlin, Maven, and Spring Boot]
* https://github.com/vaadin/skeleton-starter-hilla-react-gradle[React / TypeScript, Gradle, and Spring Boot]

For how Vaadin works with Quarkus, and with CDI on a Jakarta EE server, see <<{articles}/flow/integrations/quarkus#,Quarkus>> and <<{articles}/flow/integrations/cdi#,CDI>> in the Flow reference.


[IMPORTANT]
The <</getting-started/tutorial#,Tutorial>> and the <</building-apps#,Building Apps>> guides use Spring Boot and Maven, so parts of them don't apply as they are to projects on other platforms.
