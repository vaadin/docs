= Styling HTML Elements

Native HTML elements, like `<div>` and `<span>`, can be styled the way you would normally style HTML: with CSS and <<{articles}/styling/utility-classes#, utility classes>>. CSS class names are typically used to target specific instances of HTML elements.

[.example]
--
[source,java]
----
<source-info group="Flow"></source-info>
var warningBox = new Div("Warning!");
warningBox.addClassNames("warning-message");
----

[source,tsx]
----
<source-info group="React"></source-info>
<div className="warning-message">Warning!</div>
----

--

[source,css]
----
.warning-message {
  background-color: #ff8904;
}
----

<<{articles}/styling/utility-classes#, Utility classes>> like Tailwind CSS or Lumo Utility Classes can be applied directly to HTML elements:

[.example]
--
[source,java]
----
<source-info group="Flow"></source-info>
var warningBox = new Div("Warning!");
warningBox.addClassNames("bg-orange-400 p-20");
----

[source,tsx]
----
<source-info group="React"></source-info>
<div className="bg-orange-400 p-20">Warning!</div>
----

--

<<{articles}/styling#inline-styles,Inline styles>> can also be applied to individual elements and components.

[.example]
--
[source,java]
----
<source-info group="Flow"></source-info>
var warningBox = new Div("Warning!");
warningBox.getStyles().setBackground("#ff8904");
----

[source,tsx]
----
<source-info group="React"></source-info>
<div style={{ backgroundColor: '#ff8904' }}>Warning!</div>
----

--

<<{articles}/styling/styling-components#theme-style-properties,Theme style properties>> can be used to apply theme styles to any HTML element:

[source,css]
----
.warning-message {
  background-color: var(--lumo-warning-color);
}
----


[role="since:com.vaadin:vaadin@V25.3"]
== Theme Styles for HTML Elements

By default, native HTML elements are styled only by the browser and your own CSS. The Aura and Lumo themes can also style some of them, so that they match the Vaadin components. The `<table>` element is the one supported so far.

To have the theme style an element, add the `vaadin-themed-html` class name to it. To style every supported element in a part of the UI, add the class name to an ancestor instead:

[.example]
--
[source,java]
----
<source-info group="Flow"></source-info>
var table = new Table();
table.addClassName(Constants.THEMED_HTML_CLASS_NAME);
----

[source,tsx]
----
<source-info group="React"></source-info>
<table className="vaadin-themed-html">...</table>
----

--

In Flow, the class name is available as [classname]`Constants.THEMED_HTML_CLASS_NAME` in the `com.vaadin.flow.server` package.

To apply the theme styles across the whole application, enable the `themedHtml` <<{articles}/flow/configuration/properties#,configuration property>>. It adds the `vaadin-themed-html` class name to the page's `<body>`. In a Spring Boot application, add the following to [filename]`application.properties`:

[source,properties]
----
vaadin.themedHtml=true
----

To leave an element under a themed ancestor to the browser and your own CSS, add the `vaadin-unthemed-html` class name to that element. In Flow, this class name is available as [classname]`Constants.UNTHEMED_HTML_CLASS_NAME`, in the same class.

The theme styles have zero specificity, so your own CSS overrides them. For the Flow component that renders a table, see <<{articles}/components/html-elements/table#styling,Table>>.
